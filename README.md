# Vulkan Ray Tracer
## About
Real-time ray tracer built with Vulkan ray tracing extensions. This repository started out as a game engine with a forward renderer, which I was writing as part of the Engine & Tools course at Futuregames. I ripped out the forward renderer, as well as some other bits, and continued working on the project focusing specifically on ray tracing.

Read more about the project [here](https://sergeigrigorev.com/assets/Sergei_Grigorev_Project_Report.pdf).
## Build
Requires Vulkan SDK.

Build with CMake.

⚠️ This is an educational project never tested on a different machine. Having said that, the project should build correctly with MinGW + GCC toolchain. Builds with MSVC / Clang have issues. ⚠️
